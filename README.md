# 🪟 Fluetro OS 1.0

A modern, responsive WebOS inspired by a blend of Windows 8.1 Metro and Windows 11 Fluent Design aesthetics. Built entirely with HTML, CSS, and JavaScript, Fluetro OS brings a complete desktop experience right into your web browser.

---

## ✨ Features

* **🎨 Personalization & Themes:** Custom lock screens, theme toggles, and full wallpaper management.
* **🖥️ Desktop Environment:** Responsive layout featuring a semi-transparent frosted taskbar with system indicators and live time/date tracking.
* **🗂️ File Explorer:** Built-in file management utility equipped with a Windows-style ribbon interface.
* **🌐 Integrated Web Browser:** A multi-utility browser application hosting:
  * 🔍 Live Google search integration.
  * 🎨 Built-in Paint drawing tool.
  * 📝 Interactive Notepad app.
* **🛍️ App Store:** Integrated store interface to manage and launch applications.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Logic & Interactivity:** JavaScript
* **Styling Inspiration:** Microsoft Metro UI & Fluent Design System

---

## 🚀 Quick Start

To run Fluetro OS locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/TonyStark965-404/Fluetro-OS-1.0.git](https://github.com/TonyStark965-404/Fluetro-OS-1.0.git)
2. **Navigate into the project directory:**
  ```
  cd Fluetro
  ```
3.Open the project:
  Simply double-click index.html to open it in any web browser or use VS Code's Live Server extension to launch local development.

📸 Usage
Open Apps: Click on any taskbar icon or desktop tile to launch windows.

Window Management: Drag, resize, or close open applications seamlessly.

Customization: Head to Settings to update wallpapers.
